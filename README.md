# Java to Architecture

Practical Java lessons exploring software design, performance, and architecture. Each self-contained PDF develops the explanations, code examples, exercises, and trade-offs in full.

| 02 | [Immutability and Allocation Trade-offs](Lesson_02_Immutability_Allocation_tradeof.pdf) | Immutable registries, ownership boundaries, defensive copying, allocation, and throughput |

Read the PDF on GitHub or download it for offline study.

## Learning approach

Start with a concrete requirement, examine a plausible design and its failure modes, then compare alternatives and verify their trade-offs. Predict example outputs before running them. Each lesson distinguishes tested behaviour from expected results and untested exercises.
